# Brief kerja Tahap 6 — AntarKita (untuk agen/kontributor)

Repo: `/home/claude/antar-aja` (Expo SDK 57, expo-router, React 19, RN 0.86, TypeScript strict, zustand, Supabase JS).
Satu basis kode → 3 aplikasi: rute ada di `apps/pelanggan/app`, `apps/mitra/app`, `apps/admin/app` sebagai stub satu baris
`export { default } from '@/screens/<path>';` — implementasi layar ada di `src/screens/**`, komponen `src/components/**`, lib `src/lib/**`.
Alias `@/` → `src/`. Cek tipe: `npx tsc --noEmit` (wajib lolos). Jangan menyentuh file di luar daftar tugasmu.

## RPC backend (sudah diterapkan di Supabase)
**AntarShop katalog**: `nearby_stores(p_lat,p_lng,p_radius_km=15,p_category=null)` → ShopStore[] (+distance_km, product_count, is_open_now; p_category bisa 'minimarket'|'apotek'|'supermarket' atau brand 'indomaret'|'alfamart');
`store_products(p_store,p_q=null,p_category=null)` → ShopProduct[]; `shopping_estimate(p_service 'shop'|'market', p_pickup_lat,p_pickup_lng,p_drop_lat,p_drop_lng,p_subtotal,p_vehicle 'motor'|'car',p_route_km)` → ShoppingEstimate {fare, platform_fee, service_fee, subtotal, total, fare_motor, fare_car, car_min_budget, distance_km, duration_min, session};
`create_order({p:{ service:'shop', shop_store_id, dropoff:{lat,lng,address}, shopping_list:[{product_id,name,qty,note}|{name,qty,price,unit}], est_budget?, shop_vehicle:'motor'|'car', payment_method, paid_via, promo_code, notes, route_km, duration_min }})` → Order. Tanpa `shop_store_id` (toko bebas) kirim `pickup:{lat,lng,address}` + `shop_store` nama.
**AntarMarket**: `nearby_markets(p_lat,p_lng,p_radius_km)` → Market[]; `market_catalog(p_market)` → MarketItem[] (price = acuan per pasar / median nota driver 7 hari / acuan umum; price_source 'pasar'|'nota_driver'|'admin'|'pihps'; samples);
`create_order({p:{ service:'market', market_id, dropoff, shopping_list:[{item_id,name,qty,note}], shop_vehicle, payment_method, paid_via, notes }})` — dana ditahan = acuan + buffer 10%; total = belanja + jasa belanja (10%, min Rp8.000) + ongkir + biaya layanan.
**Driver (Mitra)**: `set_shopping_actual(p_order_id, p_amount, p_receipt_url, p_items:[{item_id|product_id,name,qty,price}])` → Order (mengganti set_shop_total; untuk market kirim harga riil per item → jadi acuan harga). Batas: ≤ max(1.3×anggaran, anggaran+50rb). Driver menerima `driver_service_share` (70% jasa belanja) + penggantian belanja setelah selesai. `driver_available_orders()` kini punya `shop_vehicle`, `driver_service_share`.
**Admin**: `admin_upsert_store(p)`, `admin_upsert_product(p)`, `admin_import_products(p_store, p_items:[{sku,name,category,unit,price,in_stock}], p_source)` → {imported}, `admin_set_product_stock(p_ids uuid[], p_in_stock)`, `admin_upsert_market(p)`, `admin_upsert_market_item(p)`, `admin_set_market_prices(p_market, p_prices:[{item_id,price}], p_source)`, `admin_market_price_stats(p_days)` → MarketPriceStat[]. Tabel bisa dibaca langsung: `shop_stores, shop_products, markets, market_items, market_prices` (select). Pengaturan margin di `app_settings`: shop_service_pct/min, market_service_pct/min, *_driver_share_pct, shop_car_factor, shop_car_min_budget (admin ubah via halaman Pengaturan yang sudah ada / RPC `admin_set_setting` bila ada).
**AntarTravel v2** (3 mode: kursi bersama = `travel_search`/`travel_book` lama; carter privat & sopir harian = permintaan+penawaran):
`travel_partners_directory(p_kind 'charter'|'daily'|'shared', p_city uuid|null)` → TravelPartnerCard[]; `travel_request_create({p:{kind, partner_id?, pickup_address, pickup_lat, pickup_lng, dropoff_address?, dropoff_lat?, dropoff_lng?, depart_at ISO, return_at?, days, pax, luggage?, accommodation:'customer'|'self', fuel:'customer'|'partner', vehicle_pref?, notes?, budget?, payment_method:'wallet'|'cash', paid_via}})` → TravelRequest (min. 2 jam ke depan, maks 3 aktif);
`travel_request_detail(p_request)` → TravelRequest + offers[] (+partner) + customer + city names; `travel_offer_accept(p_offer)` → TravelRequest (memotong AntarPay; lempar 'SALDO_KURANG:<nominal>' → pakai handleShortfall); `travel_request_set_status(p_request, 'cancelled'|'ongoing'|'completed', p_note)`; `travel_request_rate(p_request, p_rating, p_comment)`.
Mitra: `travel_partner_open_requests()` → TravelOpenRequest[] (permintaan terbuka + yang sudah diterima untuk mitra ini); `travel_offer_create(p_request, p_price, p_breakdown jsonb, p_message)` → TravelOffer; `travel_partner_register({p:{... + partner_type:'agency'|'private', offers_shared, offers_charter, offers_daily, daily_rate, overtime_rate, accommodation:['customer','self'], accommodation_fee, fuel_included, base_lat, base_lng, bio, driver_name}})`.
Pelanggan daftar permintaan: `supabase.from('travel_requests').select('*').eq('customer_id', uid).order('created_at',{ascending:false})`. Admin: `admin_travel_requests(p_status|null)` → AdminTravelRequestRow[].
Notifikasi (tabel `notifications`) untuk travel memuat `data.travel_request_id` → buka `/travel/request/<id>`.
**Payment gateway**: `gateway_public_config()` (anon) → GatewayPublicConfig; admin: `admin_gateway_status()` → GatewayStatus; `admin_set_gateway({p:{server_key?, client_key?, is_production?, merchant_id?, methods?:string[], topup_min?, topup_max?, clear_server_key?:true}})` → GatewayStatus; edge `midtrans-create` body `{action:'status'}` (admin) → {configured, source, reachable, http, message}; webhook URL: `https://qwltshvzrsykxdvhbxcv.supabase.co/functions/v1/midtrans-webhook`.
Referensi praktik (riset): travel per kursi Pekanbaru–Padang Rp120–160rb (eksekutif Rp450rb), door-to-door; rental sopir: 12 jam/hari, overtime 10%/jam, akomodasi sopir menginap ditanggung penyewa ATAU kompensasi ±Rp150.000/malam (mandiri); BBM/tol/parkir di luar harga sopir kecuali paket all-in.
